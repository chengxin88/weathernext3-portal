数据格式

每个 .npz 文件包含经度 lon、纬度 lat、二维格点 values 和 JSON 元数据 meta。气象站训练温露点为 0.05° 网格，其余变量为 0.1° 网格；覆盖范围以所选起报为准。

这是区域集合均值资料。降水为逐小时累计量，温度单位 °C、气压 hPa、风分量 m/s、云量 %、辐射 W/m²。ZIP 附带 manifest.json 和读取说明。

Python 读取示例
import json
import numpy as np

with np.load("data/f001_surface_t.npz", allow_pickle=False) as data:
    lon, lat, values = data["lon"], data["lat"], data["values"]
    meta = json.loads(str(data["meta"].item()))
    print(values.shape, meta["valid"], meta["unit"])
